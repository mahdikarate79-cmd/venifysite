# VeniFy — Telegram Gaming Bot Mini App

A modern, minimal, and visually calming web mini-app for the VeniFy Telegram gaming bot.

## Live Site

**https://mahdikarate79-cmd.github.io/venifysite/**

## Features

- Dark space-inspired theme with liquid glass UI effects
- Animated starfield background
- Help section with interactive game cards
- 4-language support: English, Russian, Arabic, Persian
- iOS-inspired dynamic island header
- Bottom navigation with disabled future sections

## Tech Stack

- Next.js 14 (static export)
- React 18
- Tailwind CSS
- Framer Motion

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
```

Static files are output to the `out/` directory.
